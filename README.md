# 何もないコース / Nothing Course

note記事と連動して制作している、オリジナルの横スクロールゲームです。

敵、穴、障害物、アイテム、スコア、制限時間はありません。小さな旅人を動かして、青空と草原の道を自由に進んでください。

## 試作品 ver.0.4（ジャンプ音・ゴール演出改善）

- スタート画面（タイトルは仮）
- 通常コース：外部素材を使用しない約17秒の明るいオリジナルBGM（C・F・Gのメジャー三和音）
- ゴール演出：通常BGMをすぐ停止 → 約1秒のオリジナル上昇ファンファーレ（「トゥルルルルル！」） → 専用BGMへ切り替え
- ゴール専用BGM：通常曲と調・拍子を変えたニ長調・3拍子のオリジナル曲（D→A→G→D→G→D→A→D、約13.6秒のループ）。ゴール演出とクリア画面で継続
- 開始・ジャンプ・着地・ゴールテープの効果音はBGMに対して約1.6倍聴こえやすく設定。ジャンプ音はタッチ・キー押下の瞬間に発音して遅延を低減
- ジャンプ音はSTART時に波形を事前生成し、入力時は専用の音声経路から即座に再生。スマホ端末・Bluetooth等による物理的な再生遅延は残り得る
- BGMと効果音の全体音量を初期版から段階的に増加。ピーク保護のコンプレッサーを使用
- 画面右上の丸い♪ボタンから音のON/OFFを切り替え（初期状態はON）
- 左右移動、加速・減速、押す長さで高さが変わるジャンプ
- 双方向の横スクロール、青空・山・丘・木々の多重スクロール
- ゴールテープを切り、笑顔でばんざいジャンプするクリア画面
- PCキーボード、スマートフォンの丸型タッチボタン
- レスポンシブ表示・縦横画面対応

## 操作方法

| 端末 | 左右移動 | ジャンプ |
| --- | --- | --- |
| PC | ← / → または A / D | Space |
| スマートフォン | 左下の丸い矢印ボタン | 右下の丸いジャンプボタン |

PCではEnterキーで開始・リプレイできます。左右を同時に押すと相殺します。ゲームオーバーはありません。

音は「START」の操作をきっかけに再生します。無音でも遊べます。ページが非表示になると音声を停止し、復帰時に再開を試みます。iPhoneで音が出ない場合は、端末の音量、消音設定、画面右上の♪ボタンを確認してください。

## GitHub Pagesで公開する

1. GitHubのこのリポジトリで Settings → Pages を開く。
2. Build and deployment の Source を Deploy from a branch にする。
3. Branch を main、フォルダーを /(root) にして Save。
4. 公開ページに表示されたURLからゲームを開く。

ゲームの公開用URLは通常 https://takashi-dotcom.github.io/nothing-course/ という形式です。実際にPagesが有効になっていることを確認するまでは公開済みとは見なしません。

## 調整するとき

- js/config.js — 移動速度、ジャンプ力、重力、ゴール位置、noteへのリンク
- js/game.js — 物理挙動、ゴール判定、画面追従
- js/input.js — キーボード・マルチタッチ
- js/render.js — 草原、雲、山、キャラクターとアニメーション
- js/main.js — 画面遷移・描画更新、効果音の呼び出し
- js/sound.js — オリジナルBGMと効果音の合成・再生、音量切り替え
- style.css — 丸い操作ボタン、文字、レイアウト
- index.html — 画面構造

ローカルで確認する場合、JavaScriptモジュールのためWebサーバー経由で開いてください。例: python3 -m http.server 8000 をこのフォルダーで実行し、http://localhost:8000 にアクセス。

## 公開前の確認事項

- [ ] iPhone Safariで縦・横表示とタッチ操作を確認
- [ ] PCでキーボード操作を確認
- [ ] 走行、ジャンプ、ゴール、再プレイを確認
- [ ] 通常BGM・ゴール専用ループBGM、開始・ジャンプ・着地・テープ効果音を確認
- [ ] ゴール直後に通常BGMが止まること、「トゥルルルルル！」の合図の後に専用曲が始まりループすることを確認
- [ ] ジャンプ音がタッチ・キーボード入力時にすぐ鳴り、二重に鳴らないことを確認
- [ ] クリア画面で音をOFF→ONに戻しても専用BGMが再開することを確認
- [ ] ♪ボタンによる音のON/OFFとタブ切り替え後の音声復帰を確認
- [ ] 画面回転やタブ切り替えで入力が残らないことを確認
- [ ] note記事が公開されたら js/config.js の noteUrl を記事URLに変更
- [ ] 実際の公開URLをnote記事に設定

## 開発方針

外部ライブラリ・外部画像・外部音声ファイルなし。軽量なCanvas描画とWeb Audio APIによるオリジナル音声合成を使用します。任天堂などのゲーム素材は使用していません。

プレイデータ・個人情報は収集せず、ログインも不要です。現在「noteへ戻る」は記事URLが未定のため作者のnoteプロフィールへ移動します。
